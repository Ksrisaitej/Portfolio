A Next.js 14 + TypeScript implementation of the supplied portfolio direction and motion reference.

```bash
npm install
npm run dev
```

## Motion notes

The implementation uses Framer Motion for scroll-linked drawing and reduced-motion support, plus Lenis for smooth scrolling. The visual language is intentionally grid-driven and avoids generic SaaS cards, neon AI clichés, excessive glassmorphism, and decorative particle effects.
